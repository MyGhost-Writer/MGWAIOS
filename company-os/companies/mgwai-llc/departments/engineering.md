# Engineering Department

## Purpose

Build, integrate, test, and deploy MGWAI software products and client systems.

## Responsibilities

- Build web apps and APIs.
- Create agentic workflows.
- Integrate external systems.
- Maintain code quality.
- Deploy to cloud infrastructure.
- Support data movement and automation.

## Inputs

- Product requirements
- Task packets
- Architecture docs
- Client context
- Existing code

## Outputs

- Code
- Tests
- Technical docs
- Deployment notes
- Pull requests
- Operational runbooks

## Agent Opportunities

- Frontend builder
- Backend builder
- API integrator
- QA reviewer
- Deployment assistant
- Data pipeline engineer

## Approval Rules

AI may create and modify code when requested.

Owner approval is required before production deployment, destructive data operations, or external system changes.
