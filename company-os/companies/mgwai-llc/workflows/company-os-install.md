# Company OS Install Workflow

## Purpose

Install MGWAIOS into a new company using leader conversation, research, source ingestion, and structured review.

## Trigger

A company wants a business-aware AI operating layer.

## End State

The company has a v1 instance under `company-os/companies/<company-slug>/` with approved profile, offers, workflows, departments, agent recipes, and initial memory.

## Steps

1. Run leader discovery conversation.
2. Gather public research.
3. Inventory available internal sources.
4. Set read-only connector boundaries.
5. Extract source notes.
6. Classify notes.
7. Draft company profile.
8. Draft offers, departments, and workflows.
9. Recommend first agent recipes.
10. Review with leader.
11. Approve v1 company OS.
12. Create first useful deliverable.

## Inputs

- Leader interview
- Public research
- Internal documents
- System inventory
- Approval boundaries

## Outputs

- Company profile
- Department map
- Workflow map
- Agent recipe set
- Automation opportunity list
- First useful deliverable

## Approval Points

- Internal source access
- Company profile approval
- Workflow approval
- Client-facing deliverables
- Any external action
